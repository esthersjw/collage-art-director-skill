# Layout grammar

## Selection rules

Choose the image role from the source rather than from a preferred template.

Use **full-image background** when:

- the environment adds meaning;
- subject separation would remove useful context;
- the source already has coherent depth or useful negative space.

Use **subject reconstruction** when:

- the subject has a readable silhouette;
- the original background is distracting or semantically weak;
- a sampled solid color can clarify the subject.

Use **break-frame hybrid** when:

- the subject or an object naturally crosses a strong edge;
- retaining part of the original scene helps recognition;
- the design needs depth without fake shadows or blur.

Use **framed image object** when:

- the photo should remain visibly photographic;
- typography needs equal weight;
- the source crop works as an independent rectangle.

Use **cropped fragments** when:

- the image contains expressive details such as hands, food, eyes, texture, signage, or objects;
- repetition creates rhythm without losing identity.

Use **multi-image narrative** when:

- two to six photos depict one event, subject, relationship, or visual motif;
- a clear hero image can be selected.

## Eight reusable grammars

### A. Full bleed / type punctuation

- Image: full canvas.
- Type: small or medium, scattered only where contrast is clean.
- Z-order: image → optional subtle contrast patch → type.
- Best for: already beautiful or atmospheric photos.
- Avoid: turning every phrase into a sticky note.

### B. Full bleed / monumental type

- Image: full canvas.
- Type: oversized and deliberately overlapping subject or architecture.
- Z-order: image → large display type → small supporting type.
- Best for: strong statement and clear subject.
- Requirement: title becomes a primary visual event, not a caption.

### C. Type behind / type in front

- Background: sampled solid color.
- Type layer 1: oversized word behind the subject.
- Subject: cutout or break-frame middle layer.
- Type layer 2: smaller phrase in front.
- Z-order: color → rear type → subject → front type → microcopy.
- Best for: a clean silhouette and short phrase.

### D. Type over framed photo

- Background: solid, paper, or flat print texture.
- Image: large photographic rectangle.
- Type: deliberately crosses the image boundary and remains topmost.
- Z-order: background → framed photo → display type → microcopy.
- Best for: image and wording as coequal materials.

### E. Editorial field

- Background: restrained solid or paper tone.
- Type: large modular words create the grid.
- Images: one hero plus small inserts overlap the words.
- Z-order may alternate: word → image → word.
- Best for: multi-image memories and magazine-like composition.
- Avoid: equal-size photo grid.

### F. Fragment labels

- Image: full bleed or framed.
- Copy: split into meaningful chunks, each on a consistent paper fragment.
- Labels: varied width, same material treatment, 2–5% canvas gap.
- Z-order: image → label set → one accent material.
- Best for: conversational or humorous wording.
- Avoid: arrows, numbered guidance, flowchart logic, crowded stacks.

### G. Object constellation

- Background: sampled solid color.
- Main subject: largest cutout.
- Supporting image fragments or theme objects: visibly smaller.
- Type: one large anchor and one micro label.
- Best for: products, food, collections, souvenirs.
- Avoid: generic sticker-sheet spacing.

### H. Multi-image asymmetric story

- One hero image occupies roughly 45–70% of image area.
- One or two support images occupy 15–30%.
- Details occupy the remainder.
- Use overlaps, rotated crops, or edge cuts with one shared alignment.
- Type bridges the images instead of sitting in a separate header.
- Avoid: three equal columns, contact sheets, and automatic masonry grids.

## Structural diversity test

For three requested directions, choose grammars from different families:

1. image-dominant: A or B;
2. subject/type depth: C or D;
3. object or multi-image composition: E, G, or H.

F may replace one family only when segmented labels suit the copy.

Reject a set when all three share the same photo rectangle, title location, or z-order.
